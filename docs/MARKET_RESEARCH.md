# تحقیق بازار — رقبای بین‌المللی مشابه سودبان

> منابع: جست‌وجوی وب (۲۰۲۶) درباره ابزارهای رصد قیمت رقیب و ابزارهای تحلیل سود واقعی فروشندگان
> آنلاین. لینک‌های منبع در پایین سند.

## دو دسته ابزار جهانی که سودبان آن‌ها را ترکیب می‌کند

بازار بین‌المللی این حوزه را عملاً دو دسته جدا از ابزار پوشش می‌دهند — سودبان هر دو را در یک
محصول واحد ادغام می‌کند:

### دسته ۱: رصد قیمت رقبا و رپرایسینگ (Competitor Price Monitoring / Repricing)
| ابزار | تمرکز |
|---|---|
| **Prisync** | رصد ساختاریافته قیمت رقیب در سطح محصول، MAP monitoring، پیشنهاد قیمت پویا؛ گزینه سریع برای زیر ۵۰۰۰ SKU |
| **Wiser** | Commerce Execution سازمانی؛ intelligence عملیاتی برای برندها و ریتیلرها |
| **Repricer.com** | رپرایسینگ پویا مخصوص مارکت‌پلیس‌ها (آمازون/eBay/والمارت)، تمرکز روی Buy Box |
| **Price2Spy** | تحلیل تاریخی عمیق، MAP compliance، مناسب audit trail |
| **Omnia Retail** | تجمیع داده از آمازون/گوگل شاپینگ + داشبورد استراتژی قیمت‌گذاری |
| **Intelligence Node** | مقیاس بالا، رفرش تا ۱۰ ثانیه، تطبیق SKU با دقت بالا |

### دسته ۲: تحلیل سود واقعی / COGS برای فروشندگان (True-Cost & Profit Analytics)
| ابزار | تمرکز |
|---|---|
| **Sellerboard** | محاسبه حاشیه سود آمازون با احتساب همه کارمزدها (FBA، PPC، انبارداری)، پشتیبانی FIFO/batch COGS |
| **Helium 10 Profits** | بخشی از سوییت Helium 10؛ نمایش سود/حاشیه به ازای سفارش و محصول |
| **Fetcher** | P&L ساده و سبک‌وزن، بدون اتوماسیون پیشرفته |
| سایر (Sellerise, ManageByStats, SellerApp, HelloProfit, Jungle Scout) | تنوع در عمق ویژگی و قیمت‌گذاری |

## جایگاه تمایز سودبان

1. **ادغام دو دسته در یک جریان تصمیم واحد**: اکثر ابزارهای بالا یا فقط قیمت رقیب را رصد می‌کنند
   یا فقط سود واقعی را محاسبه می‌کنند؛ کمتر ابزاری این دو را با یک موتور پیشنهاد قیمت + موتور
   هشدار ریسک + موتور خرد (لایه توصیه ترکیبی) به هم متصل می‌کند.
2. **طراحی بومی برای اقتصاد پرنوسان ایران**: `CostProfile` نسخه‌بندی‌شده برای تغییر سریع هزینه
   (تورم/نرخ ارز) — چیزی که ابزارهای بین‌المللی برای بازارهای باثبات‌تر طراحی نشده‌اند.
3. **کانال‌های بومی به‌جای فقط آمازون/eBay**: دیجی‌کالا، باسلام، ترب به‌عنوان کانال‌های اول‌کلاس
   (`CompetitorPrice.channel`) به‌جای وابستگی به مارکت‌پلیس‌های غربی.
4. **rationale شفاف فارسی**: به‌جای فقط یک عدد پیشنهادی، هر تصمیم دلیل قابل‌فهم (`rationale[]`)
   دارد — مشابه رویکرد Sellerboard در شفافیت محاسبه، اما برای تصمیم قیمت‌گذاری.

## ریسک رقابتی
اگر دیجی‌کالا/باسلام/ترب مستقیماً APIهای رصد قیمت رسمی عرضه کنند، بخشی از ارزش «رصد رقیب» کم‌رنگ
می‌شود؛ به همین دلیل موتور خرد (لایه توصیه ترکیبی، نه فقط داده خام) به‌عنوان تمایز پایدارتر طراحی
شده — چیزی که کپی کردنش صرفاً با scraping ممکن نیست.
